# Analytical Report

This directory presents the recommendation project in a standard analytical
report structure. Read the chapters in order:

- [Complete submission draft](FULL_REPORT.md), following the requested table of
  contents and including results, qualitative analysis, roles, time plan,
  bibliography, and appendices.
- [Formatted Word submission](Odos_Ermou_Recommendation_Report.docx), with all
  seven plots embedded, fourteen formatted tables, figure captions, page
  numbers, bibliography, and appendices.

1. [Introduction](01_introduction.md)
2. [Data collection](02_data_collection.md)
3. [Data processing](03_data_processing.md)
4. [Methodology and algorithms](04_methodology_and_algorithms.md)
5. [Experimental setup](05_experimental_setup.md)
6. [Results and quantitative analysis](06_results.md)
7. [Discussion and limitations](07_discussion.md)

The report deliberately excludes the raw order workbook because it can contain
customer and location information. All numerical results are generated by the
versioned code and CSV files under `outputs/`.

Final serving and historical model configurations, together with readable
weight tables, are under `../model_configs/`. Offline experiment programs are
under `../experiments/`. Learned graph edges and Node2vec vectors are under
`../model_weights/`.

Regenerate the Word file from the complete Markdown report with:

```powershell
python scripts/build_word_report.py
```

When the document first opens in Microsoft Word, select the table of contents
and choose **Update Field → Update entire table** so Word calculates the final
page numbers for the current installation and printer layout.
